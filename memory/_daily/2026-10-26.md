## Entry: 2026-10-26 — pnpm 12가 esbuild postinstall을 차단함
- **상황**: `remotion/`에서 최초 `pnpm install` (pnpm v12.8.1, Remotion 4.0.535)
- **증상**: `ERR_PNPM_IGNORED_BUILDS ... Ignored build scripts: esbuild@0.28.1`로 install 실패. `pnpm-workspace.yaml`의 `onlyBuiltDependencies: [esbuild]`도 무시됨
- **원인**: pnpm 12는 build script 허용 목록 키가 `allowBuilds`로 바뀜
- **해결**: `pnpm -C remotion approve-builds esbuild` → `pnpm-workspace.yaml`에 `allowBuilds: {esbuild: true}` 기록됨
- **검증**: 재실행한 `pnpm install`이 `Done`으로 끝나고 `node_modules/.bin/remotion` 존재
